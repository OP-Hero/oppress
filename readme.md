Hi, welcome to my modified vitepress version. It will automatically regenerate the sidebar if you update a markdown file in [src/](src/)

get started using `npm i` to install the dependencies.

After installing you should change the title and description in [.vitepress/config.ts](.vitepress/config.ts) and get developing your beautiful vitepress site.

You may use this in any project aslong as you give credit (may be in the readme file at the bottom if your project is open source)
